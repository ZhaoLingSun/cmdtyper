# 跟打统计与日历

日历记录对着打、命令专题、符号专题、系统专题、专题训练 L1 和场景实训中的完整命令跟打。基础三题沿用来源入口：命令基础组记为命令专题，符号组记为符号专题，系统组记为系统专题。阅读、填空、默写和诊断选择不计入这些指标。退出、跳过和重试保存已经练习的部分；只有完成输入的记录推进命令掌握度。

## 有效时长与准确率

- 第一次有效输入开始计时；两次输入的间隔最多计入 30 秒。
- 暂停、读输出及逐条命令之间等候 Enter 的时间不计入时长。
- CPM = 已完成的有效字符数 × 60000 / 有效毫秒数，WPM = CPM / 5。汇总时使用字符总量和时长总量，不平均每题速度。
- 大小写字符、空格和符号分别计量；Enter、退格和快捷键不算有效字符。
- 准确率 = 1 − 出错的目标位置数 / 已尝试的目标位置数。一个位置连续错按多次仍只记一个错误。退格不会清除错误；未完成位置发生的错误也计入。
- 跨午夜的有效时长拆分到各自本地日期；完成字符归入完成当天，准确率的位置归入第一次尝试当天。日期在输入时保存，因此更换时区不会重写新记录的归属。

## 逐字符速度

每个字符独立保留最近 50 个有效位置耗时。一个位置只有一个样本，退格回访与纠错耗时累计到原位置。

第一输入字符、每条命令的首字符、跨暂停、含超过 30 秒空闲以及零耗时的位置不进入速度样本窗口。它们仍参与练习量和准确率。至少有 10 个样本才显示速度；不足时显示“样本不足”。

先将窗口内的耗时排序，再将最快、最慢两端各 `floor(n × 10%)` 个值压到相邻边界值（缩尾）。对处理后的耗时取平均，再计算 `60000 / 平均耗时`，避免对瞬时 CPM 直接求平均导致极短间隔占主导。

字符面板展示每个字符的窗口样本数、平滑 CPM、平均耗时和位置错误率。空格显示为 `␣`。日历中的字符窗口截至所选日期，随后发生的练习不会进入该日期的窗口。同一会话跨日退格重打时，保留先前日期的位置快照，使后来的纠错或重打不会反向改变旧日速度；完整练习的完成日期也在输入时固定。

## 日历操作

- 左右方向键选择日期，上下方向键选择上一周或下一周。
- PgUp / PgDown 切换月份，Home 返回今天。
- j / k 滚动字符列表，`[` / `]` 滚动当天入口明细。
- 每日明细包括有效时长、WPM、CPM、准确率，以及各跟打入口的完成数与练习片段数。
- 低于 20 行的窗口优先显示所选日期的指标与明细；完整月历和逐字符表在较高窗口展示。

## 存储与兼容

`history.json` 保存版本 2 的位置、时段和本地日期信息；`stats.json` 保存聚合缓存与各字符的最近 50 个耗时。保留原有字段，新字段使用兼容默认值。稳定的练习 ID 支持覆盖同一片段的未完成快照；重复保存不会重复累计。

写入先保存历史，再刷新统计缓存。JSON 通过临时文件写入、同步与原子替换保存；启动时从历史恢复统计，处理历史写入成功而缓存尚未更新的中断情况。

迁移先将备份完整写入同目录临时文件、同步，再以不覆盖已有文件的方式原子发布；所有需要的备份成功后才修改原数据。既有备份保持不变；备份失败或历史损坏时停止迁移并保留原文件。命令去重迁移另存 `*.pre-catalog.bak`。

第一次统计迁移保留 `stats.json.pre-v2.bak` 和 `history.json.pre-v2.bak`。旧记录继续保留已记录的指标，并标注旧口径；无法恢复的空闲、退格位置和字符间隔不补造。仅有旧统计而无历史的安装将原统计保存到不可变的 `legacy_stats_baseline.json`，在后续重建时合并这个旧口径基线，无法推导缺失的输入事件。原有命令掌握度保留。

## 远程机器的时区

本地日期是运行 cmdtyper 的进程时区；远程机器的系统时区可能与使用者不同。本次目标主机默认 America/Los_Angeles，上海日期可使用 `TZ=Asia/Shanghai CMDTYPER_DATA_DIR=./data ./target/release/cmdtyper` 启动。这个环境变量只影响该进程，不修改服务器系统时区。已经保存的新记录保留原输入日期。
