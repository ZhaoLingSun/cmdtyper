# cmdtyper 题库、场景实训与练习统计升级

本计划于 2026-09-06 获准实施。实施基线为 `intranet:/home/ace/workspaces/cmdtyper` 当时的 554 条独立命令、75 个命令讲解及 178 项通过测试；保留当时已有的未提交工作。后续授权包括本地与远程版本管理，审查通过后直接提交并推送，推送失败不阻塞其他交付。

## 跟打与内容结构

- 将适合顺序操作的长 `&&` 命令改为有序步骤：输入完整一条后按 Enter，展示该步骤输出并进入下一条，下一次击键正常输入。准备目录、创建文件等步骤保留上下文和教学说明。
- 专门教授条件执行的 `&&` 保留；引号、管道、子 Shell 和条件依赖逐条审查，不做字符串机械切分。
- 统一使用规范命令 ID；专题、讲解、练习和实训引用同一命令，场景输出与解释保存在引用处。新增步骤序列类型，旧单条命令仍可加载。
- 完全相同的命令合并；仅规范首尾空白和换行格式，不改变引号或内部空白。不同参数和目标的有效练习变体保留。旧 ID 通过别名映射兼容历史记录与进度。
- 移除学习中心前四个重复入口，保留命令专题、符号专题、系统架构、专题训练，增加场景实训；首页增加练习日历。
- 为全部命令、符号、系统专题明确基础用法分组：每组一道教学示例，另配三道简单练习，分别训练原用法、参数变化和小任务迁移。命令基础范围覆盖全部 L1 示例，符号覆盖全部条目，系统覆盖全部章节。保留现有 L1/L3/L5 训练方式。
- 专题显示基础用法数、实际练习数和完成进度，所有数量来自数据；同一道题的不同训练模式不重复计数。
- 将目录加载、练习运行、统计聚合和场景流程拆为独立模块，避免继续向 App 堆积业务逻辑。

## 场景实训

流程为背景和目标 → 灰字跟打 → 模拟输出 → 关键证据解释 → 判断与下一步 → 修复验证 → 复盘。错误判断给出原因并引导返回证据，支持退出续练和重做。

首批 20 个案例：

1. 远程机器中断恢复后的链路、启动日志、资源与进程排查。
2. SSH 无法连接。
3. DNS 导致服务不可达。
4. 端口冲突导致服务启动失败。
5. 防火墙导致连接超时。
6. 丢包与 MTU 异常。
7. TLS 证书过期。
8. HTTP 502/504 排查。
9. 抓包定位连接故障。
10. Docker 容器网络不通。
11. Docker 网站从零部署上线。
12. Git 版本管理、发布与回滚。
13. 后端日志及接口异常。
14. PostgreSQL 查询、事务修改和验证。
15. 数据库备份与恢复演练。
16. 磁盘容量与 inode 耗尽。
17. CPU、内存与 OOM 排查。
18. systemd 服务反复退出。
19. 权限及定时任务故障。
20. 文件误操作后的备份恢复与一致性检查。

每例至少八个有教学意义的步骤及两个诊断判断点。案例间保持主机、路径、服务名和模拟状态一致。网站系列贯穿 Ubuntu LTS、Docker Compose、Nginx、FastAPI、PostgreSQL 和 Git，覆盖配置、持久卷、健康检查、HTTPS、发布、回滚和数据运维。适量加入 Python 终端命令处理 JSON、日志和简单诊断。应用只模拟教学，不执行真实命令。

## 日历与逐字符统计

- 所有完整跟打入口计入日历；阅读、填空、默写、诊断选择不计入跟打指标。使用统一记录接口及独立场景跟打模式。
- 首次输入开始计时；输入间隔超过 30 秒时，只保留前 30 秒。输出阅读和暂停不计时；退出、跳过、重试保存已练部分，完成进度与练习量分开记录。
- 按练习时本地日期归档，跨午夜按输入时间拆分。支持月份切换、日期选择、每日时长、WPM、CPM、准确率及入口明细。
- CPM = 有效完成字符数 / 有效输入分钟数，WPM = CPM / 5。每日按字符总数与时长总量汇总，不平均每题速度。
- 准确率按已尝试的唯一目标位置计算；同一位置多次误按只记一次，退格重打不清除错误，未完成位置的错误也计入。空格和符号计入，Enter、退格和快捷键不计有效字符。
- 每个字符独立保存最近 50 个有效耗时样本。位置耗时包含纠错；退格重访累计到原位置，一个位置至多一个速度样本。
- 首字符、跨暂停及超过 30 秒空闲的位置不进入速度窗口，仍保留练习量和准确率；零间隔样本不参与速度计算。
- 少于 10 个样本显示样本不足。达到门槛后按耗时排序，对两端各 10% 缩尾，再平均耗时换算 CPM，不直接平均瞬时 CPM。
- 展示字符、窗口样本数、平滑 CPM、平均耗时及错误率；空格有可见标识。窗口跨会话持久化，日历显示截至所选日期的结果。
- 记录、日统计及字符样本增加兼容字段和统计版本。旧历史可可靠重建的指标重建；无法恢复的退格、空闲及间隔不补造，明确标注旧口径。迁移前备份，写入原子化，稳定记录 ID 防止重复聚合。
